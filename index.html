Build an Agent Harness

An agent is a model plus a harness. This book builds a harness from scratch in Python, one component per chapter, and reads the real source code of four very different open-source harnesses along the way: Vercel's eve, Vercel Labs' fx, Earendil's Pi and Pi Durable, and nanocode. Each chapter explains a component from first principles, compares how each product built it and why, covers the research and how Chinese teams approach it, and ends with what we build. Written in public, one chapter a week.
